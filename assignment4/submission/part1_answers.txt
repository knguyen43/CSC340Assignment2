PART 1 - QUESTION 3: MEMOIZATION

(a) Definition of Memoization:

Memoization is an optimization technique that speeds up recursive algorithms by storing the results of expensive function calls and returning the cached result when the same inputs occur again. It transforms an exponential time algorithm into a linear one by avoiding redundant calculations.

For example, in the seriesRecursive function, calculating J(6) requires calculating J(5), J(4), and J(3). But calculating J(5) also requires calculating J(4) and J(3) again. With memoization, we would store the results of J(4) and J(3) the first time they're calculated and reuse them instead of recalculating.

Source: Cormen, T. H., Leiserson, C. E., Rivest, R. L., & Stein, C. (2009). Introduction to Algorithms (3rd ed.). MIT Press.

(b) Strategy to Implement Memoization for seriesRecursive:

• Create a storage structure (like an array or map) to cache previously computed values
• Modify the recursive function to first check if the value for n is already in the cache
• If found in cache, return the cached value immediately
• If not found, compute the value recursively, store it in the cache, and then return it
• Initialize base cases (J(0)=0, J(1)=1, J(2)=1) in the cache at the start
• The function should prioritize cache lookups before performing recursive calculations
• For larger values of n, this would dramatically reduce the number of function calls
• The time complexity would improve from O(3^n) to O(n)
• The space complexity would be O(n) for storing at most n distinct values
